# AnimeOn Hunter & Cards — Автосборщик тыкв и карточек 🎃🎴 (v1.4)

Полнофункциональное расширение для браузера (Chrome, Edge, Яндекс Браузер, Opera, Brave) и автономный скрипт (Tampermonkey/Violentmonkey) для автоматического сбора тыкв, непрерывного фонового фарма и **быстрого автооткрытия карточек и бустеров на [AnimeOn Cards](https://animeon.cc/cards)**.

---

## 🎴 Быстрое автооткрытие карточек (`https://animeon.cc/cards`)

Открытие паков через стандартный интерфейс сайта сопровождается долгими 3D/Canvas-анимациями (разрывание шва, переворачивание каждой из 5 карт, частицы, ожидание кликов). Если у вас накоплено 10–50 паков, ручное вскрытие занимает 15–30 минут.

Модуль **Fast Cards Opener**:
1. **Открытие всех сохраненных паков в 1 клик** через прямой API (`POST /api/cards/open` с параметром `source: "stored"`) на скорости до 120–250 мс за пак.
2. **Автоматический забор Бустера Дня**: бесплатный ежедневный бустер забирается мгновенно одной кнопкой (`POST /api/cards/claim`).
3. **Выборочное открытие**: можно открыть конкретный тип пака (1 шт., 5 шт. или все сразу).
4. **Автопропуск анимаций сайта (Fast Skip)**: при ручном открытии паков через сайт автоматически нажимает «Пропустить» и ускоряет анимации.
5. **Live Card Showcase (Журнал дропа в реальном времени)**:
   - Отображает выпавшие карточки с превью, названием и бейджем редкости.
   - Подсветка редких карт (Эпические, Легендарные, Мифические, Реликвии).
   - Звуковые эффекты дропа через Web Audio API (отдельные аккорды для легендарок и мификов).
   - Статистика выпадения: всего паков, карт, редких карт и новых экземпляров в коллекции.

## 🔍 Механика и серверные лимиты тыкв

Как устроена серверная система спавна и ограничений ивента AnimeOn:

1. **Дневной и часовой лимиты на сервере:**
   - Сервер передает в объекте состояния:
     - `caught_today` — сколько тыкв собрано пользователем за сегодня;
     - `daily_cap` — максимальный суточный лимит тыкв (лимит 60 тыкв в день, либо значение, установленное администрацией);
     - `caught_hour` — сколько тыкв собрано в текущем часе;
     - `hourly_cap` — максимальный лимит за 1 час.
   - Код проверки на сервере:
     ```javascript
     let isHourCapped = caught_hour >= hourly_cap;
     let isDailyCapped = caught_today >= daily_cap;
     ```
   - При превышении дневного лимита сервер возвращает ошибку:
     `pumpkin_daily_cap: "На сегодня лимит тыкв исчерпан — возвращайтесь завтра"`
   - При превышении часового лимита сервер возвращает ошибку:
     `pumpkin_hourly_cap: "На этот час тыквы закончились — загляните в следующем"`
   - **Лимит 60 тыкв:** Механика `daily_cap` заложена в архитектуру ивента. Расширение автоматически считывает `daily_cap` прямо из API и отображает точный прогресс (например: `18 / 60`).

2. **Как работает спавн тыкв каждый час:**
   - В начале каждого часа (`XX:00:01`) сервер случайным образом выбирает страницы (примерно 1 тыква на каждые 10–15 аниме).
   - Тыквы одинаковы для всех пользователей и остаются на тех же страницах вплоть до конца текущего часа.

## ⚡ Возможности автоматизации

- 🔥 **Режим «Всегда собирать тыквы» (Continuous Auto-Farm):**
  - Бот работает полностью автономно:
    1. Автоматически сканирует сайт сразу при открытии вкладки;
    2. Запускает сбор свежих тыкв в начале каждого часа (`XX:00:15`);
    3. Делает фоновую проверку каждые 5 минут во время часа;
    4. При обычном просмотре видео мгновенно забирает тыкву через DOM-кликер.
- 📍 **Где были тыквы в этом часе (История локаций до смены часа):**
  - Каждая собранная тыква сохраняется в специальный список с названием аниме, прямой кликабельной ссылкой и временем нахождения.
  - Список сохраняется **до наступления следующего часа**, чтобы вы всегда видели, где именно в текущем часе были тыквы.
  - В момент наступления нового часа таймер сбрасывается, список очищается и бот собирает свежие тыквы.
- 📊 **Индикатор дневного лимита:**
  - Отображает реальный прогресс `Сегодня: X / 60` (или `без лимита`).
- 🛒 **Прямой переход в Магазин:**
  - Быстрый доступ к покупке Premium, стикеров и бустеров.

## 📦 Установка

### Вариант 1: Браузерное расширение (Chrome, Edge, Яндекс Браузер, Opera, Brave)

1. Скачайте репозиторий (кнопка **Code -> Download ZIP** и распакуйте) либо клонируйте:
   ```bash
   git clone https://github.com/Sherik21/animeon-pumpkin-collector.git
   ```
2. Откройте страницу дополнений в браузере:
   - В **Chrome**: `chrome://extensions/`
   - В **Edge**: `edge://extensions/`
   - В **Яндекс Браузере**: `browser://tune/`
3. Включите **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите скачанную папку проекта.
6. Перейдите на [animeon.cc](https://animeon.cc/) — в углу сайта появится виджет 🎃!

---

### Вариант 2: Tampermonkey / Violentmonkey (в 1 клик)

1. Откройте Tampermonkey -> **«Создать новый скрипт»** (*+*).
2. Скопируйте код из файла [`animeon-pumpkin-collector.user.js`](./animeon-pumpkin-collector.user.js).
3. Нажмите **Файл -> Сохранить** (Ctrl + S).
4. Откройте [animeon.cc](https://animeon.cc/) — скрипт начнет непрерывный автосбор!
